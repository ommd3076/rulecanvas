# Contributing to RuleCanvas

Thank you for contributing to RuleCanvas!

## Development Workflow
1. Install dependencies: 
pm ci
2. Run syntax verification: 
pm run check
3. Execute unit test suite: 
pm test
4. Build bundle: 
pm run build
5. Run browser smoke tests: 
ode scripts/browser-smoke.mjs
